# Phase 2.2: Context & Requirements

## Overview
Phase 2.2 expands "The Swarm Orchestrator" epic to enable true autonomous CI/CD functionality natively inside Jules without requiring explicit Slash Commands. Instead of demanding a human invocation, Jules will operate implicitly in the background.

## Goal
Whenever the local `gsd` pipeline ships code as a Pull Request, the Cloudflare worker should:
1. Automatically intercept the `pull_request` webhook (`opened` & `synchronize`).
2. Bypass the explicit trigger guard (the proxy shouldn't drop the packet just because a label or `@jules` mention is missing).
3. Inject an explicit "CI/CD Orchestrator" LLM system prompt instructing Jules to:
   - Perform architectural code review.
   - Run the repository's native test suite via bash.
   - Actively merge the PR if the suite passes and security checks clear.
   - Inject blockers and feedback comments if the build is compromised.
4. Ignore any events triggered by automated bots or `jules-ai` itself to prevent recursive infinite loops.
