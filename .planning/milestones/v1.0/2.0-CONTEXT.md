# Phase 2.0: Zapier Workflow Replacement Expansion (Triggers & Notifications)

## Objective
Finalize the transition of the Jules infrastructure off of Zapier by expanding the native Cloudflare Worker (`proxy/src/index.ts`) to handle advanced webhook parsing, trigger notifications to Discord/Slack, and be securely deployed via Wrangler.

## Context
Milestone 1.0 successfully integrated the Jules proxy to listen to Github `pull_request` events and run nightly scheduled python sweeps.

To replace Zapier entirely, we must:
1. Support more than just PRs.
2. Provide outbound webhook notifications (Zapier's "Send Message" action) when operations succeed or fail.
3. Handle secure secret deployments locally.

## Focus Areas
1. **GitHub Webhook Triggers**: Accept `issues` and `issue_comment` types, adapting the label/URL/SHA payload fetching logic.
2. **Notification Actions**: Add async `sendNotification` payload functionality for generic webhook endpoints (Slack or Discord).
3. **Configuration**: Secure `.dev.vars` / Cloudflare Secrets bridging.
