# Plan 1.0-02: Scheduled Sweeps Workflow

<objective>
Create a GitHub Action to run the scheduled codebase sweeps natively within the repository structure on a CRON schedule.
</objective>

<tasks>
<task>
  <description>Create Jules Sweep Action</description>
  <read_first>
    - check_gh_jules.py
  </read_first>
  <action>
    Create `.github/workflows/jules-sweep.yml`.
    Setup the `on: schedule` trigger for `cron: '0 2 * * *'` (2AM every night).
    The steps should checkout the code, setup python, install requirements if any, and execute `python check_gh_jules.py`.
  </action>
  <acceptance_criteria>
    - `.github/workflows/jules-sweep.yml` exists
    - Contains `cron: '0 2 * * *'`
    - Executes `python check_gh_jules.py`
  </acceptance_criteria>
</task>
</tasks>

<must_haves>
- Action runs on a daily schedule.
</must_haves>
